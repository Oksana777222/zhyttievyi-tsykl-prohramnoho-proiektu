# Життєвий цикл програмного проєкту

Інтерактивна навчальна сторінка українською мовою для учнів 10 класу.

## Що містить
- теоретичний матеріал про шість етапів життєвого циклу;
- компетентнісне завдання про цифровий облік обладнання STEM-лабораторії;
- практичну роботу «Від ідеї до плану програмного проєкту»;
- форму для заповнення паспорта проєкту та завантаження результату у TXT;
- тест із 8 запитань з автоматичною перевіркою та поясненнями;
- можливість друку або збереження сторінки у PDF.

## Публікація через GitHub Pages
1. Створіть новий публічний репозиторій на GitHub.
2. Завантажте файл `index.html` у кореневу папку репозиторію.
3. Відкрийте **Settings → Pages**.
4. У розділі **Build and deployment** виберіть **Deploy from a branch**.
5. Вкажіть гілку `main` і папку `/ (root)`, натисніть **Save**.
6. Після публікації GitHub покаже адресу сторінки у розділі Pages.

Сторінка автономна: не потребує серверної частини, бібліотек або зовнішніх ресурсів.
